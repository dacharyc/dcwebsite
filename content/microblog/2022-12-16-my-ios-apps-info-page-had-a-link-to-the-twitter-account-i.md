My #ios app’s info page had a link to the Twitter account I set up for it. Given everything that is going on over there these days, I wanted to switch that to a Mastodon instance that hubby set up for our side projects.

Haven’t touched the code in 8 months. Went to archive and there were missing symbols. “Aha! I remember the #realm #swift team had a version whose release notes mentioned addressing this.” Update the version to most recent, and everything just works again.

Bonus: I wrote a zillion tests for the app back when I was actively developing it, and after updating the version, the tests all still passed!

I’ve been getting into some small semi-abandoned packages lately for some niche stuff in the new apps I’m working on, and it’s such a night-and-day difference using a project that’s actually maintained by thoughtful devs. ❤️
