The next PR Focus release is almost ready, and it brings a focus on individual contributor workflows! There is a new "Principal PRs" dashboard that shows *only*:

- My PRs
- Assigned PRs
- Reviewing PRs

For folks who don't want to watch or ignore other pull request activity in a repository, there is a setting to make this the default view in PR Focus.

And! The extra real estate for the "My PRs" list means there's space to surface more actionable information in the pull request summary. So this release adds badges for "Approved" and "Changes Requested" directly to the PR summary, meaning you don't have to click into the details and can quickly scan for actionable updates.

This release is almost ready to go - there's one more small feature I'd like to sneak in. Hoping to have it ready over the weekend!
