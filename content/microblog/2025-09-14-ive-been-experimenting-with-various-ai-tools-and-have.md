I've been experimenting with various AI tools, and have discovered how precious those premium requests are when it comes to coding-related tasks.

So I wrote a little macOS menu-bar app to help me easily keep track of the number of premium requests I have remaining. The icon color changes when I get low on requests, and if I hit the menu bar item, I can see exactly how many requests I have remaining and when they reset. Clicking on the "remaining" element takes me to the GitHub UI where I can view more about the current state of my premium requests, and could potentially add more.

This is one of those cases where I really love having development chops because then it's trivial to write little tools like these.
