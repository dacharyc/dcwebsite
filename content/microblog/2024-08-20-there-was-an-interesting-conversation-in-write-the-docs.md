There was an interesting conversation in Write the Docs about a guided code experience where explanation is presented side-by-side with code examples. As you scroll through the explanation, the code example on the right changes to reflect the next step, where the relevant content is highlighted.

Apple has my favorite implementation of this guided code experience in their developer tutorials - here's an example: https://developer.apple.com/tutorials/swiftui-concepts/scaling-views-to-complement-text

Curious how many #TechnicalWriters are doing something like this with their docs? Do you have thoughts on this way of presenting code and content? Maintenance considerations?

My team has stepped tutorials with code examples, but the presentation is very different - I really like this side-by-side component.
