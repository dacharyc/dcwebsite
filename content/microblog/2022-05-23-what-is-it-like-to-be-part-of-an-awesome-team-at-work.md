What is it like to be part of an awesome team at work?

My teammate [@bpmutter](https://github.com/bpmutter) gave a talk at the Write the Docs conference today about the value of unit testing code examples in docs, and how to do it.

Ahead of this talk, our team collaborated on a bunch of improvements to our tooling around this to prepare it for a v1 release.

Last Friday, we cut a v1.0 release of Bluehawk, our markup tool for extracting code examples and creating checkpointed tutorials. It was a team effort, and I’m super proud of how we came together to prep this release in support of Ben’s talk.

(And of course, awesome work on the talk, Ben!)

If you’re someone who needs to provide code examples in documentation, this tool might be useful to you:

https://github.com/mongodb-university/Bluehawk
