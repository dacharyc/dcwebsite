Another busy weekend for the AFDocs tool! I released v0.9.0 with some additional `--verbosity` details on page-level checks, and support for running with a config from the command line. Define the checks you want to run in a config and easily re-run as needed while you're fixing up specific issues.

I also put together a real docs site for it, with details about the new scorecard format, how to use the CLI, using it in CI, and using the library's programmatic access. And if you're a docs team wondering what to do with all this, there's an "Improve Your Score" guide, and comprehensive per-check breakdowns to walk you through what each check means and how you can fix them.

https://afdocs.dev/
