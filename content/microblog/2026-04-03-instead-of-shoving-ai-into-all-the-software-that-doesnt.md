Instead of shoving AI into all the software that doesn't need it, can someone please build the collaboration tool that is missing from my workflows?

I live in GitHub, the IDE, and the terminal all day. I use AI regularly and my local files are all markdown for simplicity.

I am increasingly working with stakeholders who live in meetings all day and rely on Google docs. They need to dip in and out of content, want it to be nicely formatted so they can scan it quickly, and want a good mechanism to have discussion about specific elements.

Sure, GitHub can do all that, but my stakeholders aren't there and it doesn't fit their flows.

So instead, I'm saving Google docs as markdown, opening them in my IDE, working with them there, then copying the contents, going back to the Google doc, and pasting as markdown to update the doc.

Can someone please just make something that can sync content between Google docs and markdown on my local file system so I don't have to do this stupid dance? Ideally, it could also sync comments so I don't have to copy/paste them, too.

I would pay money for this. Enterprises would probably pay a *lot* of money for this.

(Editing to add, based on a lot of comments about switching to other platforms - this isn't a "switch to another platform" situation. It's a "my enterprise uses Google docs for internal collaboration" situation, and trying to get things into and out of that moat for use with my agents.)
