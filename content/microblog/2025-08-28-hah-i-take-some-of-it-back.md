Hah, I take some of it back. 😂

I posted the other day about how much better Claude was than GPT 4.1 at some coding-related tasks in agentic mode.

Later, I asked Claude to break up a couple of long files that it wrote into smaller logical units to make it easier for my team to review and maintain.

It created a very reasonable implementation plan. But then it utterly failed in execution, repeatedly.

After giving it 3 chances using different prompts spanning more than an hour (I was working on different things that required a human), I took over and did it myself. It took me 5 minutes.

Can write reasonable code to accomplish a task - check.

Can refactor that code to improve readability and maintainability - apparently not 😂
