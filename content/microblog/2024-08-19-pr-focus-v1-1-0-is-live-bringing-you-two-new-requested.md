PR Focus v1.1.0 is live, bringing you two new requested features and some new accessibility settings 🎉

- *Tag PRs*. Create custom tags in PR Focus and apply them to your PRs. Track important activity across feature development, bug fixes, or a specific project - even across repos. Filter by tag and date range in the new Tagged PRs dashboard to report on activity to key stakeholders.
- *Automatically Watch, Ignore, or Tag PRs with Filters*. Create custom filters based on PR author username, title, description, or repository. With user-defined filters, PR Focus can automatically ignore Snyk dependency PRs, for example, or automatically watch or Tag PRs following a specific naming convention.
- *Accessibility settings*: display text instead of glyphs for PR status and review status.

For more details, including links to the docs for these new features, check out the announcement: https://prfocus.app/news/2024/08/12/introducing-tags-and-filtering-in-pr-focus/
