Naming things is hard.

I’m adding a new dashboard to PR Focus where people can view only the pull requests they’re involved in. This consists of two, or potentially three, lists of PRs:

- My PRs (PRs where the user is the PR author)
- Assignee PRs
- Reviewing PRs

“Mine” doesn’t work as a UI label, because most people would expect that to be just “My PRs” - not the assignee and reviewing columns.

I was thinking “Contributor”, but spousey argued you’re not really a “contributor” if you’re reviewing a PR - especially if you have only been tagged and haven’t reviewed it yet.

Spousey started suggesting acronyms - “CAR” and “RAM”, but I have SO MUCH resistance to an acronym as a UI label. I’m sure there are times where it’s the best option, but this doesn’t feel like one of them.

I have tentatively landed on “Principal” but I don’t love it.

Someone suggested “Active”, as a counterpoint to some of the other UI labels (“Inactive” and “Archived”), but there is another dashboard where you can watch PRs where you’re not a contributor, and those PRs could also be active. So that doesn’t work in the larger context of the app’s functionality.

Words are important. Getting the right word can sometimes be hard.
