I really *want* to do really cool, novel, exploratory agent experience studies and experiments. And I have faith that I’ll get there eventually.

But so far, I just keep finding myself pulled back into docs-related things.

So, PSA: before you can do all the cool stuff, you need good, up-to-date docs that agents can access. Docs are the foundations that AI model training crawlers and answer engines use to learn about your products. Coding agents refer to them in user tasks. If agents can’t access the info, or if it’s outdated or contains contradictions, you’ll have problems and nothing novel can save you.
