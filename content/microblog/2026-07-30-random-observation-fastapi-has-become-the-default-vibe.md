Random observation: FastAPI has become the default vibe-coded server. My agents basically always reach for Python/FastAPI when spinning something up that needs a server unless I specify something else, and now that I’ve seen it in a handful of my own projects, I am basically seeing it everywhere.

I would love to dig into why agents reach for this first. I’ll bet there’s a lot we could learn about agentic product selection. I’m really curious how much it is just - this is well-represented in GitHub data/public repos that a lot of agentic coding knowledge is probably based on. Or whether FastAPI inherently has any characteristics that make agents find it “easier” to use and reach for it as a default. 🤔
