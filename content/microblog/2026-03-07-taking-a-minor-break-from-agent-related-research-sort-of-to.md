Taking a minor break from agent-related research - sort of - to fix up some issues and feature requests for my newest macOS app that's in TestFlight Beta - Issuenator.

I've accumulated... kind of a lot of repos where I want to keep tabs on issues. And sometimes I file issues on other people's repos. And at work, I have a separate set of repos where I want to watch issues.

So in the spirit of PR Focus, my PR-tracking dashboard, I created Issuenator - an app for keeping track of all the issues across all the repos I care about.

I intentionally kept it separate from PR Focus because I'm really in different workstreams when I'm handling these things. PR Focus is for keeping track of my day-to-day work, and what my colleagues need from me. Issuenator is for keeping track of incoming requests from outside folks. I usually check on Issuenator at the beginning and end of the day to check for new issues or issue updates, or occasionally when I'm swapping between tasks, but otherwise don't want the noise interrupting my main workstream.

If you're a maintainer on a lot of repos, or if you file issues on a lot of repos, and you've ever wanted to keep track of all the issues in one place so nothing gets forgotten, maybe you want to give this a try. I've been in private beta for a couple of months and am pretty satisfied with the current state, so I'm thinking of opening it up to a public beta soon. If you want to try it out for free before I launch it, let me know.

https://issuenator.app/
