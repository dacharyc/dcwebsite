I wish Anthropic hadn’t added “memory” functionality to Claude Code. I almost never want it, for a variety of reasons:

- It doesn’t have good judgement about what should become a memory
- I already have project documents whose contents I curate (AGENTS.md, CLAUDE.md, skills/hooks etc.)
- I don’t want to pollute context with content that isn’t needed in every session

I generally don’t want to waste the input tokens on Claude Code reading whatever it has decided is memory, and waste generation tokens on writing it. Especially when the harness seems to “forget” memories anyway when performing tasks in-session.

Blarg.
