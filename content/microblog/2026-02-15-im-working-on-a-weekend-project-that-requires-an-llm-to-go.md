I'm working on a weekend project that requires an LLM to go read hundreds of docs links. And I am very dismayed by the state of docs for LLM consumption. I've been a little spoiled by being able to point LLMs at Markdown versions of docs pages for some of the bigger or more modern platforms, and it's a bummer how much software out there does *not* provide LLM-friendly documentation.

I keep falling back to GitHub repos, and specifically the `raw` versions of code and markdown files, and it works like a charm.

As an industry, if we can't figure out a way to elevate LLM/agent users to first-class consumers of our docs, we're just going to lose them entirely. "Skip the docs and refer to source" might become my first instruction instead of a fallback.
