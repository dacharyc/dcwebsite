It has been an awesome first week of public beta for my upcoming app, PR Focus!

I've gotten - and fixed - 4 bug reports. I'm testing a new private build today, and assuming it all looks good, I'll push out an updated build this weekend.

I've also gotten some fantastic new feature requests that I've added to the post-launch roadmap: the ability to tag and filter pull requests!

Tagging will enable you to create your own arbitrary groupings in PR Focus without having to expose the tags via GitHub. So you can tag pull requests across different repos as related to a specific feature, for example, and see them all in one place.

Filters will allow you to define custom rules to automatically Watch, Ignore, or Tag incoming pull requests. So you can automatically Ignore Snyk dependency update PRs, for example, or automatically apply specific tags for PRs matching keywords you define.

Thanks for the awesome ideas, beta testers! These new features sound great.

I've still got a few spots open in the public beta - I'd love to hear from you!
