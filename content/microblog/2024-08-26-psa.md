PSA: If you are storing static information in Discord, or requiring folks to join a Discord server to get information about your product, you’re doing it wrong.

Discord is a chat app.

If you have static information to convey, that does not belong in a chat app.

It should be a website.

Doubly so if the static information is documentation.
