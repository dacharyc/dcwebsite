The Agent-Friendly Docs Spec just got a spec bump! In v0.3.0, the spec:

- Folds the standalone `llms-txt-directive` from the former "Agent Discoverability Directives" category into the `llms.txt` category, and renames it "Content Discoverability"
- Adds a new "Recommended action" to each check with details about what to do to resolve a warn or failure state
- Adds a new "Interaction Effects" section detailing the ways certain check failures can combine to create disproportionately worse outcomes for agents

Working on updates to `afdocs` now to incorporate spec updates, and I expect those to land in the next couple of days.

Excited to keep building in this space, and keep adding details to the spec as we discover more about agent docs consumption patterns. 🎉
