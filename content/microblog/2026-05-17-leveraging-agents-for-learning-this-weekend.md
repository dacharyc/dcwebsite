Leveraging agents for learning this weekend.

I have realized that my writing-code-by-hand skills are getting rusty because I’ve been working with agents so heavily for ~8 months. So I’ve had Claude Code spin up some exercises for me just to refresh.

As expected, I retain the shape of the algorithms, but the syntax and language-specific reflexes have fallen out of my brain. So Claude broke it down further for me into drills so I can rebuild those reflexes.

Kind of alarming to see how quickly those specifics erode. But unbelievable luxury to have a tool that can create custom drills and exercises for me to practice to regain lost ground.

Also underscores where the value is. It takes me 10-20 minutes to work through a drill, or ~45 minutes for an exercise. But Claude can write equivalent code in ~2-5 minutes. We live in wild times.
